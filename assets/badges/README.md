# README badges

The preview version, project license, platform targets and Rust core badges are stored locally, so the README does not depend on a third-party badge service. Keep version and platform labels consistent with the actual packages.

## Rust logo

The Rust logo in `rust.svg` comes from the [Rust project’s official artwork](https://github.com/rust-lang/rust-artwork/blob/main/logo/rust-logo-single-path.svg), distributed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). The original vector shape is retained and resized and recolored white for the badge. The logo indicates use of Rust and does not imply endorsement by the Rust project or Rust Foundation.

The other badge artwork is part of ClickPulse under the project license.
