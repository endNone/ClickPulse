# Literary comparison references

These are playful length estimates, not writing-output measurements. The app contains only titles and rounded character counts. All languages use these same English-edition references. The 20 books combine independently with five localized phrases, giving 100 combinations.

The comparison uses Chinese titles and phrases for Simplified and Traditional Chinese. All other interface languages use the English version, including number formatting. The rest of the interface keeps its selected language.

Counts were derived from the linked public-domain texts: retain text between the Project Gutenberg start/end markers, remove bracketed illustration captions, and collapse whitespace to single spaces. Round to 10,000 characters. Pride and Prejudice retains its earlier broad 700,000-character approximation. Editions, front matter and translations vary.
