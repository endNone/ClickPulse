# Caps Lock validation — 2026-11-12

A physical-key check used the installed macOS 0.2.1 App. With the Mac ClickPulse window explicitly focused, the maintainer confirmed ten Caps Lock presses, each toggling the keyboard light. The persisted key-57 counter changed from 205 to 208 after settling: three recorded presses.

Earlier attempts overlapped virtual-machine input routing and a standalone diagnostic tap that did not reliably receive events. They are excluded from the result; the original one-count observation was provisional.

The old callback queried the current global key state and fed Caps Lock through an ordinary held-key tracker. The fix counts transitions of the Caps Lock flag carried by each FlagsChanged event, in both directions, and ignores repeated notifications with the same state. The initial state and re-enabled taps are synchronized from the system.

Regression tests exercise ten toggles from both initial states, duplicate notifications, unrelated modifier bits and synchronization after a capture gap. The patched App still requires the final physical ten-press acceptance test before publication.
