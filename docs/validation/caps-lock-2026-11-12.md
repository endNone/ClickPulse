# Caps Lock validation — 2026-11-12

The original macOS 0.2.1 capture path queried global key state. In an explicitly Mac-focused ten-press check, only three presses reached the saved counter. Earlier runs involving virtual-machine input routing are excluded.

An initial fix counted both changes of the Caps Lock flag. Physical testing rejected that approach: this Mac can emit multiple lock-state changes for one physical operation. A two-press case matched, but ten-press runs did not consistently match. No successful result is claimed for that implementation. Apple also documents a delay that can ignore brief Caps Lock taps; lock-state notifications are therefore not a reliable physical-press stream.

## Final implementation

A passive HID callback receives only the keyboard Caps Lock usage. It counts the physical down transition once per device and ignores repeated down reports and releases. The Quartz path excludes Caps Lock to prevent duplicate counting. Other keys and mouse input keep their existing capture path. Startup-held keys, disconnects and paused input maintain tracking state without inventing a new press.

## Physical acceptance

The maintainer pressed Caps Lock exactly ten times on the Mac keyboard and confirmed using the mouse. The saved counter increased from **264 to 274**. The local diagnostic contained **ten down reports and ten releases** from one keyboard; exactly the ten down reports were accepted. This verifies the input path and persisted count together. The prior two-press diagnostic and ambiguous earlier trials are not substituted for this acceptance result.

Regression tests cover ten presses with repeated reports, startup-held keys, separate devices, removal/reconnect state and pause/resume. The Mac suite passed 184 Rust tests and warnings-denied checks passed. Temporary Caps-only diagnostics are excluded from release source and packages.

References: [Apple HID input callbacks](https://developer.apple.com/documentation/iokit/1438367-iohidmanagerregisterinputvalueca), [Apple keyboard response guidance](https://support.apple.com/en-al/guide/mac-help/mchlp1240/mac).
