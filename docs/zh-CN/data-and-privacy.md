# 数据与隐私

[English](../data-and-privacy.md) · **简体中文**

## 记录什么（以及不记录什么）

ClickPulse 仅在本地 SQLite 数据库（`events.sqlite3`）中记录 **设备类型**、**按键或鼠标键位标识**、**次数** 与 **统计时间戳**。

- **绝不记录**：输入的文本内容、字符、鼠标坐标轨迹、滚轮距离、屏幕画面、当前活动窗口/应用名称或剪贴板内容。
- **长按与鼠标**：长按按键在松开前只计一次；鼠标移动、松开和滚轮不计为点击。
- **软件模拟输入**：可在设置中开启 **忽略软件模拟输入**（默认关闭），在 macOS 和 Windows 上过滤可识别的合成输入，同时保留触控板点击。

## 联网行为

所有统计数据严格留在本地，无账号、无遥测、无云同步、无数据上传。

- **更新检查**：正常桌面会话默认每 24 小时请求一次 GitHub Releases 检查更新，并在后台下载可用安装包，仅在你点击 **更新并重启** 后安装。在设置中关闭 **自动检查** 即可完全停止后台网络请求。
- **外部链接**：点击 **快捷键图鉴**、官方快捷键参考或一次性 GitHub Star 提醒时，仅在浏览器中打开对应网页，不会发送任何使用统计。

## 快捷键统计与活动报告

- **快捷键统计**：在 macOS 和 Windows 上，仅对符合条件的修饰键组合查询当前键盘布局（如德语 QWERTZ 下的 `⌘Z`）以识别快捷键；普通打字不会转换为字符，也不会保存布局名称或当前应用名。
- **日报与周报卡片**：完全在本地渲染。日报展示 24 小时分布，周报覆盖 **2–31 天** 每日独立柱状图与高峰时段；当显示时区与系统时区一致时可附带区间内最常用快捷键，不包含任何输入文本、应用名或你的时区名称。
- **AI 提示词**：纯本地生成的文本，由你自行检查并决定是否复制到外部 AI 工具，ClickPulse 不会连接任何 AI 服务。

## 数据留存与安全

| 数据 | 留存周期 |
| --- | --- |
| 分钟级明细 | 永久 |
| 近 24 小时精确滚动缓存 | 24 小时 |
| 按日、累计、按键与快捷键汇总 | 永久 |
| 诊断日志 + 最多 3 份轮转副本 | 每份上限 10 MiB（合计最多 40 MiB） |

历史数据不会按时间自动过期删除。SQLite 以 WAL 模式运行并采用事务化结构升级，正常退出前会刷盘保存缓冲数据。若数据库或偏好文件损坏/不可访问，软件会先保留原文件备份再提示处理，绝不静默覆盖。各平台目录与备份导入规则见[使用指南](usage.md#数据目录备份与导入)。

## 文学作品字数对比

活动日历会将所选区间内的键盘敲击次数（不含鼠标点击，按 1 次按键 ≈ 1 个字符估算）与 20 部经典著作做趣味对比。所有参考字数均为内置数字，不会下载任何电子书，详见 [literary-references.md](../literary-references.md)。

## 公开反馈注意

提交 Issue 时请使用 `--demo` 演示数据或脱敏截图，切勿上传真实数据库、原始日志或个人路径。
