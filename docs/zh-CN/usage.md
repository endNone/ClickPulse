# 使用指南

[English](../usage.md) · **简体中文**

## 页面一览

| 页面 | 功能说明 |
| --- | --- |
| **总览** | 今日/近 24 小时、近 7 天与累计统计，滚动窗口、14/30/90 天趋势、键鼠占比、小时分布及近一年活动日历 |
| **历史记录** | 每日趋势柱状图、可拖拽时间范围的小时分布散点图、年份筛选与分页明细 |
| **热力图** | 键盘热力图（**默认**或**带小键盘**）与**矩形树图**，下方展示累计**鼠标按键**分布 |
| **快捷键** | 累计快捷键次数、Top 8 排行、可搜索列表，并可一键打开网页版跨系统[快捷键图鉴](https://endnone.github.io/ClickPulse/) |
| **报告** | 日报（24 小时）与周报/多日报告（2–31 天），带扇形卡片风格切换器、PNG 导出、剪贴板复制与 AI 海报提示词 |
| **Mini / Sport** | **320 × 208** 悬浮小窗，可选开启按键速度评级（C/B/A/S/SS）与 Warp 动效 |
| **设置** | 主题、字号、语言、统计周期、时区、记录权限、开机自启、更新与数据管理 |

点击顶部按钮或按 **⌘B**（Windows/Linux 为 **Ctrl+B**）可折叠或展开侧边栏；侧边栏状态与热力图布局偏好会自动记住。

## 热力图、快捷键与活动报告

- **热力图**：长按同一按键松开前只计一次；鼠标仅统计按键点击，不记录移动和滚轮。可在顶部切换 **默认** / **带小键盘** 布局，或切换到 **矩形树图** 对比各按键占比与次数；悬停鼠标示意图会与右侧列表双向联动高亮。
- **快捷键**：统计当前系统下记录到的组合键（图表与排行中不含仅 Shift 的组合）。在 macOS 和 Windows 上，字母、数字与常见标点会自动适配当前键盘布局（如 AZERTY、QWERTZ、Dvorak）；Linux 按物理 US 键位统计。点击卡片右上角的 **快捷键图鉴** 可在浏览器中查看交互式跨系统对照表（或查看 [shortcuts.md](../shortcuts.md)）。
- **活动报告**：
  - **日报**展示所选日期的 24 小时分布。
  - **周报 / 多日报告**支持 **2 至 31 天** 任意区间（默认近 7 天），每一天独立绘制一根柱子（不合并日期），并标注最忙单小时与最忙时段。
  - 通过浮动扇形卡片切换不同配色/风格，点击 **保存 PNG** 或 **复制图片**（macOS/Windows）即可分享。
  - 展开下方 **AI 提示词** 可复制结构化海报指令，点击 **重新生成** 可变换设计风格与亮点组合。

## Mini 模式与 Sport 动效

点击右上角按钮进入 **Mini 模式**。拖动品牌区域可移动窗口，顶部可置顶、隐藏或展开回主窗口，底部可暂停/继续记录。

在 **设置 → 个性化** 中开启 **Sport 模式** 后，Mini 窗口右上角会出现闪电开关。Sport 按最近 1 秒的键鼠合计速度（CPS）实时评级（**C** < 2、**B** ≥ 2、**A** ≥ 5、**S** ≥ 8、**SS** ≥ 12）并播放 **Warp** 动画；隐藏窗口、切回主窗口或系统开启“减弱动态效果”时会自动停止渲染。

## 统计周期、时区与个性化

- **统计周期**（**设置 → 应用**）：可为总览与 Mini 选择 **自然日**（从所选时区零点起算）或 **最近 24 小时**（滚动 24 小时）。
- **时区**：默认跟随系统，也可搜索并指定任意 IANA 时区。切换时区只改变展示视角，不修改数据库中的原始时间戳。
- **外观**：内置 4 套主题（**Blue**、**Teal**、**Violet**、**Graphite**）、6 档字号（80%–150%）与 8 种界面语言。

## 后台运行与更新

- **macOS**：关闭主窗口或隐藏 Mini 后会在菜单栏继续后台记录并隐藏 Dock 图标；选择 **退出 ClickPulse** 或按 **⌘Q** 可保存并退出。
- **Windows / Linux**：可在 **设置 → 关闭行为** 中选择关闭窗口时最小化到托盘或直接退出。
- **自动更新**：在 **设置 → 应用 → 应用更新** 中默认每天自动检查并在后台下载新版本，仅在你点击 **更新并重启** 后才安装。Scoop/WinGet 安装版会提示对应的命令行升级方式。从 **0.3.2** 起 macOS 公开发布包改用固定自签证书，从 0.3.1 及更早版本升级需重新授权一次输入监控（见 [macOS 安装指南](install-macos.md#4-update-and-refresh-access)）。

## 数据目录、备份与导入

| 平台 | 统计数据与设置 | 诊断日志 |
| --- | --- | --- |
| macOS | `~/Library/Application Support/ClickPulse/` | `~/Library/Logs/clickpulse.log` |
| Windows | `%LOCALAPPDATA%\ClickPulse\` | 数据目录内的 `logs\clickpulse.log` |
| Linux | `$XDG_DATA_HOME/ClickPulse/`（默认 `~/.local/share/ClickPulse/`） | 数据目录内的 `logs/clickpulse.log` |

- **更改保存目录**（**设置 → 数据管理 → 更改目录**）：先复制并校验 `events.sqlite3` 再切换，保留原目录副本。
- **导入数据库**：可合并另一台电脑的 ClickPulse `events.sqlite3`，重复导入同一历史不会翻倍计数；导入前会自动在 `backups/` 中创建恢复点（自动保留最近 5 份）。
- **安全恢复与卸载**：数据目录丢失或文件损坏时会弹出安全恢复选项，不会静默清空数据。Windows 端可在 **设置 → 应用 → 卸载与数据** 中明确选择保留或删除本地历史。

更多隐私保证与留存规则请见[数据与隐私](data-and-privacy.md)；命令行只读查看（`--source-db`）和显式迁移（`migrate`）请见 [Development](../development.md#paths-and-explicit-migration)。
