# Security policy

The latest preview is the current security-fix target; no long-term-support versions are defined.

Report disclosure of activity records, unexpected uploads, data corruption, permission abuse or package-integrity issues privately. Do not post exploit details, real databases or raw logs in public issues.

A verified private reporting channel has not been configured yet and must be established before public release. If it is unavailable, request a private contact in a normal issue without disclosing vulnerability details or sensitive evidence. No response-time commitment is made until that process is established.

Include version, platform, minimal reproduction steps, impact and redacted evidence. Prefer synthetic data.
